Or try the computer's name

http://{{ name }}:{{ port }}

This works on some networks and devices but not all, and phones often can't use it. The address above is the dependable one.

If it stops working later

  • The address can change when the computer or the network restarts. Come back to this page on the tracker computer (or look at the window it runs in) and use the new address.
  • To make the address stay the same, whoever looks after the building's network can reserve it for this computer. They only need the computer's name ({{ name }}) and its physical address (on Windows: open Command Prompt and type ipconfig /all).
  • If phones can't connect even with the right address, the wifi may be set to keep devices apart (often called guest wifi or client isolation). Try the computer on the same network as the phones, or ask whoever looks after the network.
